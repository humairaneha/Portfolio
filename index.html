Featured Work

Featured Project

Assistive Object Identification System

Developed an assistive object identification system for visually impaired users using a pretrained YOLOv8 model, locally curated datasets, Bangladesh currency recognition, and Raspberry Pi deployment for real-world inference.

  • Dataset preparation and curation
  • Indoor object and Bangladesh currency detection setup
  • System integration using pretrained YOLOv8
  • Raspberry Pi deployment for edge inference
  • Testing and evaluation in real-world scenarios
